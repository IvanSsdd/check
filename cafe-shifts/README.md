# Отметка смен 



## Запуск за 5 минут

Нужен Python 3.11+.

```bash
python -m venv .venv
pip install -r requirements.txt
```

1. Скопируйте `.env.example` в `.env`.
2. Укажите `BOT_TOKEN` от BotFather.
3. Задайте уникальные логины и надёжные пароли менеджеров.
4. В `seed.py` замените демонстрационные Telegram ID и имена на реальные.
5. Выполните `python seed.py`.

В двух терминалах запустите:

```bash
python -m app.bot
```

```bash
uvicorn app.web:app --reload
```

Откройте http://127.0.0.1:8000. Браузер запросит Basic Auth:
- Точка А: `MANAGER_A_USERNAME` / `MANAGER_A_PASSWORD`
- Точка Б: `MANAGER_B_USERNAME` / `MANAGER_B_PASSWORD`

Тесты: `pytest -q`.

## Требования и реализация

- Telegram ID сотрудника связан с одной точкой через `employees.location_id`.
- Повторный «Пришёл» не создаёт смену и возвращает понятный ответ.
- «Ушёл» закрывает открытую смену; 22:00–02:00 даёт 4 часа.
- Частичный уникальный индекс запрещает две открытые смены одного сотрудника.
- Точка менеджера определяется только серверной учётной записью. `location_id` не принимается из URL или тела запроса.
- Месячные часы считаются одним SQL-запросом с `SUM(julianday(...))` и отсечением по границам месяца.
